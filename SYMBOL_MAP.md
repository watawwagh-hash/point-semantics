## The Cycle

```
TAKE → HOLD → RELEASE / LOOP
```

- **TAKE (الأخذ)** — the point as extraction site: *from here, take what is asked.* In `f(.)` the dot is the position, not the value.
- **HOLD (المسك)** — an effect needs one step to arrive: `rel ≥ 1`. The take is measured by distance from the point's origin, never by a stored value.
- **RELEASE (الإفراج)** — the yield. `=` is not assignment; it is what the extraction manifests.
- **LOOP (الحلقة)** — recurrence (3): the yield returns to the field; the decision re-enters the cycle.
